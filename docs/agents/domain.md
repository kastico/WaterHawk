# Domain docs

Layout: **single-context**. One `CONTEXT.md` and `docs/adr/` at the repo root.

Before exploring, read `CONTEXT.md` (if present) and any ADRs in `docs/adr/` that touch the area being changed. If they don't exist, proceed silently; they are created lazily when terms or decisions get resolved.

Use the vocabulary defined in `CONTEXT.md`. If output contradicts an ADR, flag it explicitly rather than silently overriding.
